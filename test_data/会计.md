# CoursePilot RAG 评测讲义：会计学基础与借贷记账

本讲义用于测试课程知识库的检索、引用和拒答能力。讲义只记录下文明确写出的知识；没有写出的具体准则编号、税率、行业特殊会计处理和金额标准，不应由助教自行补充。

## 1. 会计的基本假设与目标

会计以货币为主要计量单位，对特定主体的经济活动进行确认、计量、记录和报告。

会计通常建立在以下基本假设之上：

1. 会计主体：会计核算所针对的特定单位或组织，明确会计确认、计量和报告的空间范围。
2. 持续经营：假设企业在可预见的将来会持续经营下去，不会破产清算。
3. 会计分期：把持续经营过程划分为若干相等的会计期间，以便分期结算账目和编制财务报表。
4. 货币计量：以货币作为主要计量单位，综合反映企业的经济活动。

会计的目标是向财务报告使用者提供与企业财务状况、经营成果和现金流量等有关的会计信息，反映企业管理层受托责任履行情况，有助于使用者作出经济决策。

## 2. 会计要素与会计等式

### 2.1 会计要素

会计要素是对会计对象的基本分类，常见包括：

| 会计要素 | 基本含义 |
|---|---|
| 资产 | 企业过去的交易或事项形成的、由企业拥有或控制的、预期会给企业带来经济利益的资源 |
| 负债 | 企业过去的交易或事项形成的、预期会导致经济利益流出企业的现时义务 |
| 所有者权益 | 企业资产扣除负债后由所有者享有的剩余权益 |
| 收入 | 企业在日常活动中形成的、会导致所有者权益增加的、与所有者投入资本无关的经济利益的总流入 |
| 费用 | 企业在日常活动中发生的、会导致所有者权益减少的、与向所有者分配利润无关的经济利益的总流出 |
| 利润 | 企业在一定会计期间的经营成果，包括收入减去费用后的净额等 |

### 2.2 会计等式

基本会计等式为：

```text
资产 = 负债 + 所有者权益
```

反映经营成果的等式为：

```text
收入 - 费用 = 利润
```

在会计期末，利润归入所有者权益后，基本会计等式仍然成立。任何一笔经济业务的发生，至少引起两个会计要素或同一要素内部两个项目发生变化，但会计等式两边始终保持平衡。

## 3. 借贷记账法与会计分录

### 3.1 记账规则

借贷记账法以“借”和“贷”作为记账符号，基本规则是：

```text
有借必有贷，借贷必相等
```

每笔会计分录至少涉及两个账户，借方发生额合计等于贷方发生额合计。

### 3.2 账户结构

常见账户的增减方向可以概括为：

| 账户类别 | 借方 | 贷方 |
|---|---|---|
| 资产类 | 增加 | 减少 |
| 负债类 | 减少 | 增加 |
| 所有者权益类 | 减少 | 增加 |
| 收入类 | 减少 | 增加 |
| 费用类 | 增加 | 减少 |

### 3.3 分录示例

企业用银行存款购买原材料，价款为 1000 元，不考虑增值税等其他因素。该业务使原材料增加、银行存款减少，编制会计分录如下：

```text
借：原材料    1000
    贷：银行存款    1000
```

该分录中，借方“原材料”表示资产增加，贷方“银行存款”表示资产减少，借贷金额相等。

## 4. 会计凭证、账簿与账务处理流程

会计凭证是记录经济业务、明确经济责任的书面证明，分为原始凭证和记账凭证。原始凭证是经济业务发生时取得或填制的凭证；记账凭证是根据审核无误的原始凭证填制的、作为登记账簿依据的凭证。

账簿是由一定格式账页组成的，以会计凭证为依据，全面、系统、连续地记录各项经济业务的簿籍。常见账簿包括总账、明细账和日记账。

账务处理流程通常包括：

1. 确认经济业务；
2. 取得或填制原始凭证；
3. 审核原始凭证并填制记账凭证；
4. 根据记账凭证登记明细账和总账；
5. 期末进行对账和结账；
6. 根据账簿记录编制财务报表。

## 5. 权责发生制与收付实现制

权责发生制要求：凡是当期已经实现的收入和已经发生或应当负担的费用，不论款项是否收付，都应当作为当期的收入和费用；凡是不属于当期的收入和费用，即使款项已在当期收付，也不应当作为当期的收入和费用。

收付实现制则以款项的实际收付作为确认收入和费用的依据。

| 比较项 | 权责发生制 | 收付实现制 |
|---|---|---|
| 收入确认依据 | 是否属于当期已实现 | 是否在当期收到款项 |
| 费用确认依据 | 是否属于当期已发生或应负担 | 是否在当期支付款项 |
| 常见应用 | 企业财务会计 | 预算会计等场景常见 |

权责发生制下，期末通常需要处理应计、预收、预付、应付和折旧摊销等跨期项目，以使收入与相关费用在所属期间配比。

## 6. 财务报表的基本构成

财务报表是对企业财务状况、经营成果和现金流量的结构性表述。常见财务报表包括：

- 资产负债表：反映企业在某一特定日期的财务状况，列示资产、负债和所有者权益。
- 利润表：反映企业在一定会计期间的经营成果，列示收入、费用和利润。
- 现金流量表：反映企业在一定会计期间现金和现金等价物的流入和流出。
- 所有者权益变动表：反映企业在一定会计期间所有者权益各组成部分的增减变动情况。
- 附注：对报表列示项目的文字描述或明细资料，以及对未能在报表中列示项目的说明。

资产负债表基于“资产 = 负债 + 所有者权益”编制；利润表基于“收入 - 费用 = 利润”反映经营成果。现金流量表通常将现金流量分为经营活动、投资活动和筹资活动三类。

## 7. 会计信息质量要求与谨慎性

会计信息质量要求通常包括可靠性、相关性、可理解性、可比性、实质重于形式、重要性、谨慎性和及时性。

谨慎性要求企业对交易或事项进行会计确认、计量和报告时保持应有的谨慎，不应高估资产或者收益、低估负债或者费用。但谨慎性不意味着可以随意设置秘密准备，也不意味着可以故意压低资产或抬高负债。

历史成本是常见的计量属性之一，指资产按照购置时支付的现金或者现金等价物的金额，或者按照购置资产时所付出的对价的公允价值计量。会计计量还可能涉及重置成本、可变现净值、现值和公允价值等属性，具体选择取决于相关准则和业务性质。

## 8. 会计处理检查清单

处理一项经济业务时，可以依次检查：

1. 该业务引起了哪些会计要素或具体项目的变化。
2. 受影响账户分别属于资产、负债、所有者权益、收入还是费用类。
3. 每个账户应记借方还是贷方。
4. 借方发生额合计是否等于贷方发生额合计。
5. 收入或费用应归属的会计期间是否符合权责发生制。
6. 是否需要处理跨期项目，如应计、预付、折旧或摊销。
7. 该业务对资产负债表、利润表和现金流量表分别产生什么影响。
8. 会计处理是否符合可靠性、相关性、可比性和谨慎性等质量要求。

这些检查项只用于辅助会计处理，不代表存在适用于所有企业、所有行业的绝对规则。
